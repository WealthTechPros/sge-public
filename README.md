# SGD — Specification-Governed Development *(public distribution)*

**Public, redacted distribution of SGD by [WealthTech Pros](https://wealthtechpros.com).**

SGD (Specification-Governed Development) is a framework for keeping AI-generated code
coherent, traceable, and auditable — so regulated firms can adopt AI coding tools
(Claude Code, Copilot, Cursor) without their codebase drifting apart.

This repository is the **public, redacted** distribution: the openly shareable parts
of the SGD methodology, with IP-sensitive platform internals (the RepoSentry GitHub
App implementation, proprietary scoring/inference, and commercial detail) removed.

## Scope

| Included here | Not included (proprietary) |
|---|---|
| Methodology overview, principles, the six disciplines | RepoSentry App source / hosting |
| Public skill & workflow concepts | Proprietary scoring, capability-inference internals |
| Getting-started guidance | Client/commercial detail |
